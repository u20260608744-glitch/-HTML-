# 六种完整风格

风格用于新项目的外框、字体、密度、材质表达和动效。源图像的固有颜色/比例/内容保持不变；源模型只改变可回退的表现材质，不改变形体或功能语义。

## 选择方式

先识别读者和内容：技术对比重图纸与数字；概念汇报重主图与结论；公众/招商重空间体验；作品集重项目叙事。给用户推荐1种及备选1–2种，不问十几个色值。未指定时，概念模型项目可选深林编辑，纯图纸项目可选白纸作品集，并说明该选择。

默认一种风格贯穿整份页面。用户要求多风格成品时，保留主题切换并验证每种主题；仅要求“可选多种风格”则提供本包风格预览和可配置tokens，不增加正式页面杂乱按钮。

每个ID代表一套完整风格。用户说“采用A，可切换B与C”时，记录 `themeId=A`、`enabledThemeIds=[A,B,C]` 与 `themeSwitcher=true`；A作为初始主题，同样出现在切换集合里。按三套风格分别落实其布局、字体与图面，并验证三者切换。只有用户明确希望混合时，才将某风格的网格与另一风格的配色组合，并清楚命名这种定制方向。

这些是可适配方向，不意味着某项目只能用一种风格。`assets/theme-presets.json` 提供 palette、字体fallback、layout与motion的初始值；图框数量与字号仍须按内容/屏幕核算。

## 布局差异如何实现

使用共同组件 `Hero / SiteAtlas / SchemeCards / Masterplan / Section / Programme / Comparison / SourceBook`，根据主题的layout id改变：

- 编辑式：主图约占宽度55–65%，说明窄栏，章标题与小索引分开。
- 作品集：图像分组形成不同大小的阅读节奏，完整源图的图注仍跟随图像。
- 蓝图：固定注释侧栏与统一图框，网格淡于重要图线，尺寸层级明确。
- 展馆：居中舞台、有限行长与展签；不要把必要指标藏进模态框。
- 瑞士：所有主次信息落在同一列系统，数字与单位用独立槽位，删除无用装饰。
- 展廊：放大主图和主结论，详情区沿页继续；需要图文同显时仍保持相邻并列/上下连续。

改变布局要保持每组比较图同高、对应文字轨道同序。主题切换后重新测量frame与字体换行；不能只替换背景色便宣布6种风格完成。

## 功能色与主题色分离

`theme.accent` 是按钮/选中/章节提示色；`programmeCategories[].color` 是功能语义色。功能色由项目注册表决定，整个网页共用。任何主题下都有编号+文本+必要pattern，选中态用outline/underline等叠加；不能让绿色按钮被误读为景观类型。

功能分类可为住宅/配套/景观/水/到达，也可为诊疗/教育/展陈等项目实际类别。不得固定五类。类别来源不明确时先用原色/中性色，等待映射，不为了视觉丰富猜语义。

## 字体、图纸和灯光

- 优先使用用户有许可的本地字体，保留许可证；没有时用系统fallback。提供字体fallback不等于跨设备效果已验证，仍需截图。
- 中文正文尽量统一一个清晰字体族。大标题可有风格，正文/表格不能用装饰手写体。真实需要本地字形subset时，收集全部实际动态文本并核验字形覆盖，不照搬原项目801个汉字子集。
- 方格纸用CSS/SVG程序生成淡细线即可，密度响应缩放；网格不盖重要图线。轻纸纹可程序生成/授权材质，不能用噪声遮挡资料。
- 源图禁止任意tint、拉伸或AI重画以服从主题；需要新的表现图时从可信几何渲染，并标明派生图。
- 主光基于可见面和图面层次布置；各方案比较共用光照尺度。技术主题可少阴影，展馆主题可暖色工作室阴影；真实太阳分析另需完整分析条件。

## 动效与状态

模型自动旋转、书页动效、章节转场、主题过渡分别配置。系统`prefers-reduced-motion`下默认停止自动旋转、取消非必要翻页/镜头动画；用户仍可主动操作。动画暂停后保留当前视图，主题/语言切换不得偷偷恢复。

主题切换不改变模型coordinates/source IDs、配景点位、功能颜色含义、册页图、指标及已选方案。只在主题明确要求的初始观看表示中切材质；用户手动选材质优先保留。

## 小型验收

对最终生成的所有主题检查：正文对比度与字号可读、按钮/选中态清晰、图纸不受主题变色、长中英文不溢出、动态减少偏好有效、手机/桌面都能实际操作。同一dataset切主题，来源与数值须完全一致。

本包风格预览是视觉示意，使用示意图形，不能当作完成的新项目或通用建模器。预览无模型解析/指标计算能力，正好用来让用户选择方向。
