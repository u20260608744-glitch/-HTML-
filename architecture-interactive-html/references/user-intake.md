# 用户填写表与下次使用方式

可直接复制下面的表，填写知道的内容并附资料。填“不知道/见附件”即可。模型负责从附件提取其余信息，只有影响真实功能的缺项再追问。

视频是可选输出；只要求HTML时跳过视频附表，缺旁白/配乐不阻塞HTML。请求视频时阅读 [视频制作流程](video-production.md)，可使用 [视频输入模板](../assets/video-intake.json)，不要求用户填写程序字段。

## 首批信息：所有项目都用

```text
使用 architecture-interactive-html SKILL，为以下项目生成交互 HTML。

1. 项目名称：
2. 项目类型、地点与设计阶段：
3. 页面给谁看，主要用途：
4. 现有资料（文件名/路径/附件/链接）：
5. 一个方案还是多个方案？各自名称/对应文件：
6. 必须讲清的任务、设计目标与限制（可写见附件）：
7. 希望包含的章节或必须保留的原章节：
8. 希望有的交互（模型旋转/视角/热点/剖面/指标比较/翻册/仅图纸等）：
9. 语言（中文/英文/双语/其他）：
10. 风格（任选，也可让模型推荐）：
    深林编辑 / 白纸作品集 / 蓝图技术 / 砂岩展馆 / 瑞士网格 / 单色展廊
11. 是否要求成品里切换风格：否 / 是（列出想保留的风格）
12. 输出：单文件离线 HTML / 本地文件夹 / 在线页面（发布另行确认）；如需汇报视频，再填可选视频附表
13. 目标屏幕与体积要求（不知道可空）：
14. Logo、品牌色或字体要求（可空）：
15. 原文件不可改动范围、允许的设计补充范围（默认只制作网页）：

请先核查文件，并返回“已具备 / 真正缺项 / 可先做”及推荐模块。
不要重复索取附件里已有的信息。缺少几何、尺度或统计依据时保持未知。
```

## 需要真实模型交互时补充

```text
原模型文件/软件版本：
浏览器可用导出文件（已有才填，例如GLB）：
单位（米/毫米/其他/未知）：
坐标轴/原点/真北（已有来源才填）：
各方案对应的模型组/图层/场景（可由附件提取）：
建筑主体、场地、周边、配景的区分（已有命名则见模型）：
功能分类与对应对象/图层/册页：
需要剖切的方向、位置、标高或原生场景：
必须保持的相机、几何、材质与已有配景：
```

不要求用户手填顶点、三角面索引或程序ID。模型有明确层级时直接提取；只有无法确定哪个组属于建筑时再用图层名/截图圈选确认。

## 需要总图与指标时补充

```text
总图来源及版本：
用地/红线面积与来源：
建筑基底/占地面积及口径：
住宅/办公/商业等分项面积与来源：
地上/地下/总建筑/计容面积各自口径：
限额、容积率、建筑密度或控制条件（有哪个填哪个）：
停车：实际数量/车库面积/仅概算/未知；概算效率假设：
图纸单位、已知尺寸、比例或配准控制点：
指北针依据：真北/模型+Y/图上已有方向/未知：
有冲突的指标/页码（如有）：
```

“见面积表/任务书”也是有效输入。未核实的值不要编造，模型会先提取并给出差异表。

## 需要场地分析/原册/案例时补充

```text
场地边界与底图：
道路、设施、周边层数/高度与研究范围资料：
若要求覆盖面积，已有测绘/着色片区/统计口径：
原册文件或顺序页图：
想引用的案例/借鉴机制及图片授权/署名：
是否允许联网补充公共案例/地域背景：
```

未提供案例不影响其他模块。卫星目测或着色分析不能直接证明实际高度、步行距离或建筑覆盖率。

## 可选：需要汇报视频时补充

已有会话或附件已说明的内容直接提取，不重新询问。制作适配下载文件与登录平台发布是不同任务。

```text
是否需要视频：否 / 是；用途与观众：
使用的HTML/资料路径或附件（多版本时注明要使用哪版）：
时长：约___分钟 / 严格不超过___秒；若要求5分钟内，按≤300秒验收、目标295秒规划
必须讲清的重点与可选内容（可写见已有任务书）：
原册/图纸：选重点 / 全部快速浏览 / 逐页详解；不知道可让模型按时限建议
真实互动：需要哪些方案/视角/功能/剖面/比较/翻页操作（可写沿用HTML可用功能）：
旁白：语言、声音偏好、语气；或使用已有授权录音 / 无旁白 / 让模型推荐
音乐：原创合成 / 已有授权音乐（附来源与许可） / 不需要 / 让模型推荐
字幕：画内字幕 / 外置SRT / 两者；语言：
画面：横屏 / 竖屏 / 两者；渠道或设备、分辨率/文件大小要求（不确定可空）：
视觉：沿用HTML主题 / 六种风格之一 / 品牌要求 / 让模型推荐：
交付：MP4、封面、字幕、ZIP或其他；输出位置（可空）：
仅制作下载文件 / 另有明确上传发布任务（说明平台与范围）：
```

英文女声、舒缓原创配乐、横竖1080p是可覆盖预设，不是每个项目必填或必选项。会话或HTML已明确语言、声音、比例时沿用，未有既定偏好时可采用预设并说明。模型负责提取方案数、册页数、DOM操作、源hash、实际音频长度与技术参数。没有HTML时使用真实素材来源清单；无旁白设voice.enabled=false并按画面阅读时间排镜。没有真实模型/录制工具时先交付可做的图文片或分镜；未满足明确指定能力时说明边界，不能冒称完整交互演示。

## 两种下次调用方式

**已安装此技能的 Codex/GPT 工具环境**：输入 `$architecture-interactive-html`，附上上述首批信息及项目资料；其余参考文件会按任务需要读取。

**普通 GPT 对话环境**：上传此技能压缩包，或同时上传 `SKILL.md`、`input-requirements.md`、`build-contract.md`、`styles.md`、`acceptance.md`；附项目资料。然后使用：

同时请求视频时，再附 `video-production.md`、`video-intake.json` 与 `video-manifest.schema.json`；无执行工具也可用于制作讲稿和分镜。

```text
请采用附件中的 architecture-interactive-html 技能。
先读取SKILL.md，并按输入条件表核查我的项目资料。
先输出已提取信息、真实缺项、能力分级、模块计划和风格推荐；
继续完成已有资料能支持的部分，再生成完整可保存的HTML。
未能读取、执行或验证的能力要明确说明，不能模拟真实3D或编造建筑指标。
```

在只有文本生成能力的环境，生成 HTML 代码仍需要用户保存并实际打开；不能声称已运行。没有三维解析能力时，可先用真实图纸构建交互阅读版，再补可信模型导出。

视频调用示例：

```text
请使用技能中的video-production流程，把我的HTML/资料制作成建筑汇报视频。
严格不超过5分钟，先按295秒预算规划，语言与声音按上面的偏好。
先核查来源、实际可录制的互动与工具，再给短稿、覆盖表和分镜。
按实际配音时长排镜；真实模型操作原速，保留字幕并制作我所请求的比例。
最终验证容器时长≤300秒。仅制作本地下载文件，不自动发布。
若当前环境无法录制、配音、编码或验证，明确已完成和未完成部分，不虚构成片链接。
```

## 新项目资料的建议目录（可选）

```text
项目/
  brief/           任务书、规划条件、项目说明
  source-model/    原模型与可信导出
  drawings/        总图、平面、剖面、功能图
  metrics/         面积与停车等统计
  site/            红线、测绘、卫星影像、现场照片
  book/            原册或有序图页
  brand/           Logo及品牌约束
  references/      案例出处与允许使用的素材
  video/           请求视频时的讲稿、录制、时间轴、音轨与派生下载文件
```

目录名不是必须；按用户已有组织读取，勿要求用户为了技能重命名所有文件。
