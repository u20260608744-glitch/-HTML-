# 输入条件：用户提供什么，模型提取什么

## A. 最小输入与完整能力

页面的视觉和交互能够复用，建筑事实必须重新输入。输入可以是文件、表格、链接或自然语言，不要求用户交齐固定格式。

**最小图文版**：项目识别信息 + 至少一份可读取的图纸/图片/文字 + 展示目标。语言、风格与输出方式可按用户偏好或说明后的合理默认值决定。只有文字时可以建立文字型页面，不能说已拥有建筑图或模型。

**与参照成果相近的完整模型版**：上项 + 可解析原模型/可信导出 + 方案/主体识别 + 图纸或可从模型生成的总图/剖面 + 有来源的指标与功能说明 + 用户所需的原册/场地资料。三维、空间语义、指标、地理分析分别判断，不能捆绑声称。

**可选汇报视频**：仅在用户请求时启用。图文片可由真实图纸/文字制作；真实互动片还需要可运行的指定HTML、可见模型/操作及录制工具。旁白、音乐、字幕和编码分别检查能力与许可，不因HTML可用就自动成立。详细流程见 [video-production.md](video-production.md)，视频使用独立 [输入模板](../assets/video-intake.json) 与 [schema](../assets/video-manifest.schema.json)。没有视频输入不影响HTML构建。

视频模板英文女声与双比例是可覆盖默认，已有会话/HTML语言、声音和比例要求优先。无HTML图文片以source_assets记录素材，source_html及其hash保持null；无旁白以voice.enabled=false明确，不把缺音轨说成配音完成。

## B. 必须由用户提供或确认的事项

已有资料回答的部分由模型提取，不再询问。表中的“需确认”只在资料不足或冲突影响任务时适用。

| 输入 | 用户最方便的提供形式 | 模型可自动完成 | 缺少时处理 |
|---|---|---|---|
| 项目名称/标识 | 一句话、任务书、封面 | 提取名称、建立稳定 project_id | 暂用文件名/工作名并标为暂定，正式标题待补 |
| 项目类型、阶段、读者 | “办公概念，给业主汇报” | 推导阅读重点和适用章节 | 可以先做通用展示；不编造报批/建成状态 |
| 页面目的 | 汇报、比较、招商、作品集、公众展示等 | 选择密度与入口 | 推荐一种并说明，不加未要求功能 |
| 内容资料 | 模型、PDF、PPTX、CAD、图纸图片、文字 | 列资产、解析页序、提取正文 | 无内容则先给输入表，不能复建不存在的项目 |
| 指定交互 | 模型、热点、剖切、比较、翻页等 | 制作能力依赖表 | 无依赖资料则改成真实图文能力；所指定能力待补 |
| 方案数量与名称 | 多方案文件/图层/册页标题 | 识别 N、建立稳定 scheme_id | 有冲突时只问映射；不能固定三方案 |
| 限制条件/设计边界 | 任务书、规划条件、用户文字 | 抽取退线、高度、面积、数量、保留条件 | 缺项保持 unknown；不擅自深化建筑 |
| 单位/比例/坐标轴 | 源模型单位、CAD标注、测绘说明 | 读取 metadata、验证已知长度 | 可无标尺预览；不能输出真实尺度与面积结论 |
| 主体/场地/周边识别 | 已命名层级/图层，或用户圈选说明 | 从源结构映射，输出候选确认范围 | 歧义时问局部映射；不能仅靠材质白/绿猜 |
| 功能/楼层语义 | 功能图、图层、楼层表、文字映射 | 匹配对象与源页 | 可旋转原模型；不能伪造功能着色/楼层爆炸 |
| 指标的版本和统计口径 | 面积表/计算书/Excel/CAD注释 | 提取、检查合计、记录来源和分母 | 不明确的数保持空，不把 total_modelled 当法定面积 |
| 输出语言 | 中文、英文、双语或其他语种 | 翻译界面与资料说明，保留原名 | 默认沿用户语言；不必强制双语 |
| 风格/品牌约束 | 风格ID、参考图、Logo、品牌手册 | 推荐布局、设计tokens、字体回退 | 使用说明后的推荐风格；缺Logo不虚构机构标识 |
| 输出与访问方式 | 单HTML/本地文件夹/在线；目标设备 | 判断可离线嵌入及体积预算 | 默认本地可阅读；公开发布另行获得授权 |

## C. 按模块准备资料

| 模块 | 理想输入 | 支持格式/替代 | 原资料不足时可交付 |
|---|---|---|---|
| 首页与任务 | 项目名称、摘要、目标、代表图、Logo | PDF封面、任务书、文字；Logo选填 | 简洁项目首页；仅真实提供的图 |
| 场地 | 位置、红线、卫星/航片、周边道路/设施/高度资料 | DWG/DXF、PDF、PNG/JPG、可信地理文件 | 来源明确的静态场地说明，未知位置不造地图 |
| 城市/区域定位 | 城市、经纬度或可信地址、区域边界 | GeoJSON/SVG、用户地图、可核公共资料 | 文字定位；无法访问/核实的底图不称实际地理配准 |
| 设计回应 | 场地问题、任务要求、设计概念 | 用户文字、册页、汇报笔记 | 有出处的整理；新建议标为设计回应 |
| 形体方案 | 各方案模型/轴测/说明 | SKP/3DM/IFC/BLEND/GLB/GLTF/OBJ及工具可解析导出；仅图片也可 | 图片方案卡片、优势/待解决事项；无3D则无旋转 |
| 总图 | 同版总图、边界、单位、基底、北向、标尺 | CAD、矢量PDF、配准图片、原模型正交投影 | 图纸阅读；无尺度保留原图已有标尺，不新造标尺 |
| 剖面 | 切线/方向、标高/层高、原图或可切几何 | CAD/PDF/原生剖面场景/模型 | 原剖面放大；纯图片不能提供真切剖slider |
| 功能 | 项目实际功能分类、源图、对象映射、动线说明 | 图层表/功能册页/JSON/用户确认 | 功能图和说明并列；无对象映射禁伪热点 |
| 指标比较 | 同阶段同口径的各方案指标、限制值 | Excel/CSV/原图表/用户值 | 有来源的表格；无共同口径不强排评分名次 |
| 停车 | 实际停车布局/数量或车库面积与效率假设 | 平面、统计表、自然语言 | 实际数/概算分别显示；无资料不硬填车位 |
| 场地尺度分析 | 周边建筑类型、层数/高度及研究范围 | 已标注分析图、调查表、测绘模型 | 按源图总结；覆盖片区、建筑基底、覆盖率分开 |
| 参考案例 | 项目名、借鉴问题、授权图片/出处 | 用户案例/可核官方来源 | 可留空，不拿其他项目当本项目效果图 |
| 原方案册 | 完整PDF/PPTX/按顺序页图 | 多个有顺序图纸亦可 | 真正提供的图纸画廊；不编造“完整册” |

### 模型格式说明

- 优先读取用户现有源格式，不要求为页面重建模型。是否支持 SKP/3DM/IFC 等取决于当前环境的真实解析器，不仅取决于文件后缀。
- 若无对应解析器，请求由现有软件导出的 GLB/GLTF 或其他可读几何，以及方案/功能对象映射；原生源保留用于核对。
- OBJ 可缺单位、层级和纹理，要一起提供这些信息；GLTF 的单位约定也要与原模型尺度核对，不能仅靠后缀保证正确。
- DWG/DXF 是图纸来源，不自动等于完整三维建筑。需要建模时另立明确补模范围；图片/PDF不能直接冒充可精确编辑模型。
- 不让普通用户填写程序三角索引/PID；有解析工具时由模型提取，只有分组歧义才让用户确认对象名/圈选。

## D. 模型自动提取、用户确认歧义的字段

文件路径与hash、模型对象ID、图层/层级、单位/轴、几何包围盒、原生相机、材质、图纸宽高、册页数、目录/页码、指标单位/合计、语言文本、图像署名、已有链接。自动提取值要保留来源；冲突时记录两份证据和差异，不静默合并。

例如：源册叫“L型”而模型呈内院环形，用稳定方案ID关联，展示名称冲突待确认；总面积包含地下但容积率只计地上，不因数字齐全就自行确定计容。

## E. 可选输入

场景演示相机、光照倾向、是否使用草图纸、品牌色/字体许可、动画偏好、菜单精简、是否保留风格选择、文件体积上限、已有运行环境、部署目标、案例引用要求、现场照片、气候分析、是否打印/导PDF。没有这些不应阻塞普通页面构建。

配景规则只在确需增加人/车/树时询问：点位、密度、避让范围、固定seed；已有源配景可保留。地形需要可靠高程，不从卫星绿地颜色猜起伏。真实日照需要地点、日期时刻、朝向、坐标与算法，不能用观看阴影代替。

## F. 推荐提问顺序

1. 先读取资料，回答“我找到了什么、能做什么”。
2. 首批只问用途/目标能力/交付与风格（资料已包含的跳过）。
3. 只有阻塞当前能力时再问单位、方案对象映射、图纸配准或指标口径。
4. 实现主阅读页后再补 optional 品牌/案例/视图偏好。

输出缺项表建议格式：`字段 → 现有证据 → 状态 → 影响模块 → 用户最小补充`。对资料缺失不重复索要整包，也不把可选项变成硬门槛。

## G. 视频输入的必需、提取与选填

以下只用于已请求的视频任务；资料或会话已给的信息自动提取。

| 分类 | 输入 | 缺项与处理 |
|---|---|---|
| 必需/已知任务约束 | 可读取内容、讲解目标、必须覆盖条目；用户已指定的语言、硬时限、互动、比例与交付范围 | 无内容不能生成项目事实；明确指定的能力缺条件则说明阻塞。5分钟内按最终容器≤300秒、目标295秒规划 |
| 真实互动的条件 | 指定源HTML或可信现成录制；正确模型/语义及实际操作可运行 | 无模型可做图文片；无浏览器/录制工具可先做短稿分镜，不称已录制 |
| 使用音频的条件 | 用户授权录音、当前可用且许可适用的TTS/音乐，或实际可执行原创合成 | 许可不明确不擅用；工具不可用时保留稿与镜头，不能称已满足指定旁白/音乐 |
| 自动提取 | HTML/资产hash、章节、方案ID、功能分类、原页数/页序、控件与状态探针、来源定位、音频时长/词边界、帧时间轴、编码/画幅/QA环境 | 冲突只问映射或版本；未知保持null/not_run，不让用户手填程序细节 |
| 选填 | 声音音色/语气、配乐风格、封面、品牌动效、六种主题、多风格样片、字幕语言、体积偏好、维护脚本 | 采用已说明的合理选择，不把英文女声、64BPM或双比例变成所有项目门槛 |

视频能力记录为“讲稿分镜 / 图文讲解 / 真实互动 / 语义指标讲解”，与HTML已有能力关联但不混称。覆盖表区分展示、快速浏览、详细讲解；页数与方案数从当前项目读取。视频上传条件按对应渠道核查，朋友圈/视频号/聊天文件不混用，不能用本地技术验收代替平台实际上传。
